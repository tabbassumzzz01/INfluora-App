INFLUORA STARTER PROJECT

Files: index.html, style.css, app.js

RUN WITH VS CODE:
1. Extract this ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click index.html and choose Open with Live Server.

ALTERNATIVE:
Run `python -m http.server 8000` in this folder, then visit
http://localhost:8000

CAMERA:
Camera access generally requires localhost or an HTTPS website.
Allow camera permission in your browser.

NOTE:
This is a front-end demo. Campaigns are stored only in browser memory.
Login, database, real applications, cloud uploads, Firebase and production
security are not included.
